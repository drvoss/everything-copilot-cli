# copilot-native-workflows

Turns GitHub Copilot CLI's own features into working procedures: Plan Mode, Autopilot, background delegation, session and cross-session memory, IDE-to-CLI switching, plus Actions failure triage, PR workflow, and stack detection.

> Generated by `scripts/build-plugin-bundles.mjs` from `plugins/bundles.json`.
> Edit the skills under `skills/` in the repository root — not the copies here.

## Install

```bash
copilot plugin install copilot-native-workflows@awesome-copilot
# or, straight from this repository:
copilot plugin install drvoss/everything-copilot-cli:plugins/copilot-native-workflows
```
